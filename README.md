# Number Guessing Game (0–31)

This project is a simple number guessing game where the user thinks of a number between **0 and 31**, and the program guesses it based on the user's responses. The project includes both a **console-based C version** and an **interactive web version**.

---

## 🚀 Live Demo  
👉 [Click here to PLAY](https://tarunsingh1803.github.io/number-guessing-game/)

---

## 🖥 Console Version (C Language)

- **File:** `Game_Tarun.c`  
- **Executable:** `Game_Tarun.exe`  
- **How it works:**
  - Displays 5 different 4x4 blocks of numbers.
  - The user answers YES/NO if their number is present in each block.
  - Based on responses, the program calculates and displays the guessed number.

### ▶️ How to Run
1. Compile using a C compiler (e.g., `gcc Game_Tarun.c -o Game_Tarun.exe`)
2. Run the executable: `./Game_Tarun.exe` (or double-click on Windows)

---

## 🌐 Web Version (HTML/CSS/JavaScript)

- **Files:**
  - `index.html` – Main page structure
  - `style.css` – Styling for the interface
  - `script.js` – Game logic and interaction
- **Features:**
  - Clean UI with responsive design.
  - Interactive buttons to simulate YES/NO answers.
  - Displays the guessed number dynamically.

### 🌍 How to Play
1. Open `index.html` in your browser.
2. Click **"Start Game"**.
3. View each block and click **"Yes"** or **"No"**.
4. Your number will be revealed at the end!
